# Mikasa Custom Voiceover Directory

Place your custom audio recording here!

### Supported filenames:
- `mikasa_whoami.mp3` (Recommended)
- `mikasa_whoami.wav`
- `mikasa_whoami.ogg`

When this file is present, Mikasa will play your authentic custom voiceover whenever you ask:
- *"Who am I?"*
- *"Tell me about me"*
- *"Do you know who I am?"*
- *"Amar shomporke bolo"*

If no file is uploaded yet, Mikasa automatically uses her ultra-fast Gemini 3.8 Flash Lite HD voice (`Kore`).

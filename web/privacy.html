Privacy Policy

Last Updated: September 22, 2026 • Domain: mikasa.mrswapnil.me

This Privacy Policy describes how Mikasa Autonomous AI Operating System ("Mikasa", "we", "us", or "our"), developed and operated by Md. Miftahur Rahman Swapnil, handles data, authentication credentials, and third-party API interactions.

1. Nature of the Application

Mikasa is a private, dedicated executive AI assistant designed for personal productivity, project management, and automated engineering workflows. The system does not offer public user accounts, does not collect public consumer data, and does not sell or commercialize any personal information.

2. Information Collected and Processed

  • Communication Data: Messages exchanged with the Telegram Bot (@mikasa_360_bot) and through the web Commander HUD are processed solely to generate contextual assistant responses and distill user tasks, goals, and decisions.
  • Third-Party Platform Data: When authorized by the owner, Mikasa interacts with third-party APIs (including GitHub, X/Twitter, LinkedIn, and Facebook) using private developer access tokens strictly to read public profiles, fetch repository states, or publish approved content.
  • Authentication Credentials: All API keys and secrets are stored strictly in protected local environment files (.env) and are never exposed publicly, transmitted to untrusted parties, or logged.

3. Third-Party Integrations & Scope Usage

Mikasa connects to the following external services strictly under user authorization:

  • X (Twitter) API: Used to inspect authenticated profile status, follower metrics, and publish owner-approved technical updates. No user tracking or non-owner data analysis is performed.
  • LinkedIn API: Used strictly to publish owner-approved technical career updates.
  • Meta / Facebook Graph API: Used to share owner-approved community and project updates.
  • GitHub API: Used to query repositories belonging to Swapnil-360 to track project milestones.
  • Supabase: Serves as the encrypted cloud database for storing tasks, goals, decisions, and distilled memories.

4. Data Storage and Security

All persistent operational data is hosted securely within dedicated, access-controlled Supabase cloud instances utilizing Row-Level Security (RLS) and SSL/TLS encryption in transit. Local agent execution runs within restricted node environments without public external write access.

5. Cookies and Web Analytics

The public web interface at mikasa.mrswapnil.me does not utilize third-party tracking cookies, advertising trackers, or fingerprinting scripts. Standard server access logs are retained strictly for security and operational monitoring.

6. User Rights & Data Erasure

Because Mikasa is a dedicated single-owner personal operating system, all stored conversation memories, notes, and task records can be permanently deleted at any time via the /clear command in Telegram or via the web Commander Terminal.
